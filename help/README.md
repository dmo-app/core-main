# Ajuda distribuída com o Core

Os JSON nesta pasta são cópias dos [ficheiros de ajuda do CORE-MANUAL](https://github.com/dmo-app/CORE-MANUAL/blob/main/plugins/help-windows/README.md). O Core inclui-os no pacote e lê-os localmente. Editar o conteúdo no CORE-MANUAL e correr o sincronizador documentado nesse repositório para atualizar as cópias.
