# Core para Windows

Extrai o pacote e abre `Core.exe`. Mantém o motor `core-engine.exe` e a pasta `help` junto do executável. A ajuda incluída pode ser aberta em **Help > How the plugins work**.

O [guia de utilização do Core](https://github.com/dmo-app/CORE-MANUAL/blob/main/referencia/core/COMO-USAR.md) descreve os comandos, a instalação e as limitações. O [catálogo de plugins e samples](https://github.com/dmo-app/CORE-MANUAL/blob/main/referencia/README.md) também está no CORE-MANUAL.
